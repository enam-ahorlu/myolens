# Scope change log

Scope froze when the clock started. Thereafter, an addition is admitted only when its absence
makes an already-frozen item **non-functional** — not incomplete, non-functional — and every
addition must be funded by de-scoping something else. "It would be better if" is not a trigger;
it is an entry in the evolution plan.

**An empty log is the best possible outcome.** It is kept here so that if the rule is broken,
the breach is recorded rather than absorbed.
